# 페르소나 파일럿 B안 (모의창구 방식) — 설계와 1차 결과

> 2026-11-26 결정. A안(문장 단위 읽기 + 예/아니요 답)은 아래 이유로 중단하고 B안으로 진행한다.
> 이 문서가 A안 명세서(persona_test_spec.md)를 대신한다. A안 스크립트(01~07)와 결과(results/)는 기록용으로 남긴다.
> 결과는 모두 **가상고객 LLM 시뮬레이션**이며 실제 소비자 조사가 아니다.

## 1. 왜 B안인가 (A안에서 드러난 문제)

| 문제 | A안에서 확인한 사실 |
|---|---|
| AI가 보험을 원래 잘 앎 | 아무것도 읽지 않아도 4문항 95~100% 정답. "위 정보만으로 판단" 지시문은 효과 없음 |
| 확신 없으면 '아니요'·'판단 불가' | 정답이 '아니요'인 문항은 몰라도 맞힘, '예'인 문항은 판단 불가로 빠짐 → 결과가 조항 난이도가 아니라 정답 방향을 따라감 |
| 질문이 답을 암시 | "수술·방사선·항암 없이 호르몬제만"처럼 약관 정의를 그대로 옮긴 문장 |

모의창구(https://modu.smap.site, 2026 금융 AI Challenge 출품작, 우리 기획의 모티브)는 이 문제를
**"문서를 덮고, 남은 기억으로만 답하게 한다"** 로 푼다. B안은 그 공개된 동작을 따라 만들었다.

## 2. 흐름

```
설명서 ──▶ ① 핵심 사실·창구 질문 생성 (AI, 6개)
   │
   └──▶ ② 읽기: 가상고객이 설명서를 읽고 덮은 뒤 '머릿속에 남은 것' K개를 자기 말로 적음
                 K = 금융 친숙도별 기억 개수 (지식 하 5 / 중 7 / 상 9)
              │
              ▼
        ③ 답하기: 문서 없이 메모만 보고 창구 질문에 말로 답함 (+ 확신 1~5, 가입 판단)
              │
              ▼
        ④ 채점: 채점관 AI가 문서 기준 답과 비교 → 1 / 0.5 / 0점, 치명적 오해 여부, 근거 한 줄
              │
              ▼
        ⑤ 집계: 문항별 이해·일부·못 함·치명적 오해, 집단별 평균(중요도 가중 100점), 가입 판단

        ⑥ 기준값: 메모 없이(읽지 않고) 같은 질문에 답해 채점 → AI 상식만으로 맞히는 정도
```

- **'모름'은 0점(이해 못 함)** 으로 센다. 판단 불가를 따로 빼지 않는다.
- **치명적 오해** = 없는 보장·권리를 있다고 믿거나 받을 금액을 실제보다 크게 믿는 경우. '모름'과 구분해 센다.
- 가상고객 읽기·답변은 생각 기능 끔, 문항 생성·채점은 생각 켬(정확도).

실행: `python scripts/b_modu_style.py all` (단계별: questions / read / answer / grade / baseline / report)
결과: `results_b/` (facts.json, reads.jsonl, answers.jsonl, grades.jsonl, baseline.jsonl, report_b.md)

## 3. 1차 결과 요약 (48명, 6문항, 호출 167회, 약 $0.17)

| | 평균 이해도 |
|---|---|
| 읽고 메모로 답한 가상고객 | **38.9점** |
| 읽지 않음 (기준값 10회) | **16.0점** |

- 6문항 중 5문항은 읽지 않으면 10번 모두 만점 실패 → **읽기 효과를 잴 수 있게 됨**.
- 가장 많이 틀린 것: **합병증·호르몬제 보장 제외** (못 함 79%, 치명적 오해 25명), **가입 1년 내 진단 시 50%** (만점 17%).
- 지식 상 43.0 > 중 39.3 > 하 36.1 (기억 개수 규칙이 반영된 차이).

자세한 내용: `results_b/report_b.md`

## 4. 남은 과제 (확정 전 사람이 해야 할 것)

판단 기준별 근거 자료는 [EVIDENCE.md](EVIDENCE.md) 에 정리한다.

1. **문항 승인**: 핵심 사실·질문은 AI가 자동 생성한다. 실행 전에 사람이 확인·수정하는 단계를 둔다 (A안의 C2 와 같은 역할).
   1차 문항 중 F1 은 질문이 헷갈리고, F5 는 숫자 암기에 가깝다.
2. **채점 검수**: 채점관도 틀린다. 예) 설명서와 맞는 "중입자 5천만원"을 치명적 오해로 판정한 사례. 치명적 오해는 사람이 확인한다.
3. **가상 인물**: 지금은 A안 48명(AI 생성 배경 이야기, 수원·남성 교사 편중)을 재사용.
   모의창구가 쓰는 NVIDIA Nemotron-Personas-Korea 는 **라이선스(공개 레포 업로드·서비스 사용 가능 여부) 확인 후** 도입 검토.
4. **기억 개수 규칙**: 하 5 / 중 7 은 모의창구 화면 값, 상 9 는 추정. 연령대와 연결하는 규칙은 아직 없음.

## 5. Sona 서비스(Spring)로 옮길 때 영향

B안은 답이 예/아니요가 아니라 **자유 서술 + 점수** 이므로 현재 ERD 와 맞지 않는 부분이 있다. 팀 논의 필요.

| 현재 ERD | B안에서 필요한 것 |
|---|---|
| `questions.reference_answer` (YES / NO) | 기준 답 문장 + 근거 문장 + 중요도(1~3) |
| `experiment_responses.selected_answer` (YES / NO / UNSURE) | 답변 문장, 본인 확신(1~5) |
| `experiment_responses.grading_result` (CORRECT / INCORRECT / UNDETERMINED) | 점수 1 / 0.5 / 0 + 치명적 오해 여부 + 채점 근거 (1=CORRECT, 0=INCORRECT 는 그대로, 0.5 는 새 값 필요) |
| (없음) | 가상고객별 '머릿속에 남은 것'(메모), 첫인상, 가입 판단 |

오해율 정의(오답 + 판단 불가)는 B안의 "이해 못 함(0점)" 과 같은 생각이라 그대로 이어진다.
